## 箇所1：文字列を配列に変換する処理

```swift
let firstMBTI = Array(first.mbti.uppercased())
let secondMBTI = Array(second.mbti.uppercased())
```

**何をしているか：**
MBTIをすべて大文字に統一。
文字列を配列に変換して、1文字ずつ比較できるようにする。

**なぜこう書くのか：**
MBTIの4つの文字をそれぞれ比較する。
文字列のままだと処理ができないため配列に変換しなければならない。

**もしこう書かなかったら：**
あれいを使わなかったら番号を使って取り出せずエラーになる。
firstMBTI[0]が使えなくなる。

## 箇所2：EとIの条件判定

```swift
if eScore > iScore {
    result += "E"
} else {
    result += "I"
}
```

**何をしているか：**
EとIの点数を比較して、点数が高い方の文字を診断結果に追加している。同点の場合はIになる。

**なぜこう書くのか：**
診断で回答した内容から、MBTIの4文字を決めるため。また、同点の場合でも診断結果が出るようにしている。

**もしこう書かなかったら：**
>を>=に変更すると、EとIが同点だった場合にEが選ばれるようになる。そのため、同じ回答でも診断結果が変わる可能性がある。

## 箇所3：条件が合っている人だけの計算

```swift
if preferredGender != "どちらでも" && candidate.gender != preferredGender {
    continue
}
```

**何をしているか：**
希望した性別と違う参加者は候補から外す。

**なぜこう書くのか：**
希望条件に合わない人の相性点数を計算しないようにするため。

**もしこう書かなかったら：**
希望していない性別が入ってしまう。条件に合わない人も相性計算をしなければならなくなる。
